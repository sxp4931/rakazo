# Skill attribution

Skills in this directory are vendored from upstream repos via a local
SuperSkill bundle, under their original licenses (full texts in `licenses/`).
Sources and hashes are pinned in [`skills-lock.json`](../../skills-lock.json).
`systematic-debugging` drops upstream's skill-authoring eval files
(`CREATION-LOG.md`, `test-*.md`); everything else is verbatim.
